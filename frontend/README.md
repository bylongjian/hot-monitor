# AI热点情报台 前端说明

前端基于 React 19 + TypeScript + Vite，负责热点雷达、监控词管理和系统设置界面。

## 运行方式

开发模式：

```bash
cd frontend
npm install
npm run dev
```

生产构建：

```bash
cd frontend
npm install
npm run build
```

构建产物位于 `frontend/dist`，由后端 `backend/main.py` 统一托管。

## 当前界面能力

- 顶部壳层：统一为“热点情报台”布局，集中展示调度器状态、扫描状态、监控规模和主操作按钮“刷新热点”
- Dashboard 热点流：支持最新发现、热度综合、来源排序和热度筛选，并增加战情摘要区与视图控制台
- 关键词页：支持关键词与账号监控、启停、删除、查看命中记录，页面结构升级为“监控词编排台”
- 设置页：支持 OpenRouter、扫描间隔、最低入库热度、通知阈值、SMTP 配置，并增加控制室概览卡片
- 扫描状态联动：前端根据后端真实扫描状态自动刷新，而不是固定盲刷
- 时间展示统一：热点时间、关键词检查时间、顶部状态时间都采用同一套产品化时间格式

## UI 设计说明

- 默认深色科技风，品牌名为 `AI热点情报台`
- 视觉方向调整为更克制的编辑台/情报台风格，强调信息密度与决策效率
- 使用 Tailwind CSS、Framer Motion 和定制 UI 组件
- 常驻动画已做减负，并兼容 reduced motion
- 时间文案采用双层结构：主文案显示相对时间，副文案显示绝对时间，悬停显示完整时间

## 面向 Skills 封装的页面语义

- 顶部壳层“热点情报台”：对应系统级能力入口，包含扫描触发、调度器状态、扫描状态、热点总量、监控词总量和下次调度时间
- Dashboard“热点雷达”：对应查询类 skill 的主视图，强调热点列表读取、组合筛选、排序切换和详情展开
- Keywords“监控词编排台”：对应监控管理类 skill，适合抽象为新增监控、停用监控、删除监控、查看命中历史四类动作
- Settings“系统控制室”：对应配置类 skill，适合抽象为读取当前配置、更新扫描参数、更新通知参数、发送测试邮件四类动作

> 后续封装 skill 时，不建议直接描述视觉实现细节，而应优先复用这些页面语义和后端接口动作命名。

## 目录说明

- `src/pages`：页面级组件
- `src/components`：布局、热点卡片和 UI 组件
- `src/api/client.ts`：接口类型与请求封装
- `src/lib/utils.ts`：样式合并和时间格式化工具
